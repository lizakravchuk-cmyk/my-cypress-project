# Cypress BDD Automation

Automated 6 BDD scenarios from Module 2 using Cypress + Page Object pattern.

## Scenarios covered
1. Successful user registration
2. Successful sign in to the website
3. Update user profile information
4. Add item to the cart
5. Find exact product on the site
6. Change website language

## System under test
https://practicesoftwaretesting.com

## Run tests
npx cypress run --browser chrome
npx cypress run --browser firefox
npx cypress run --browser edge
